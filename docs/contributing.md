# Contributing

Back to the [README](../README.md).

This is a personal project: the code behind [daveyhughes.com](https://daveyhughes.com),
built for one site and maintained by one person. I'm not looking for contributions, so
issues and pull requests may go unanswered.

You're welcome to fork it and run your own. The code is licensed under the
[GNU General Public License v3.0 or later](../LICENSE.md): a fork keeps that license and
its notices, and when you distribute your version, its source goes with it under the same
terms. Point `[license].source` in your `config.toml` at your fork, so your About page
links your code rather than this repository.

The photographs on daveyhughes.com aren't part of this repository, and the GPL doesn't
cover them.
